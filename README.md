##🧰 Caixa de Ferramentas
Um mini site interativo para facilitar duas tarefas do dia a dia: sortear um nome e calcular o preço com desconto.
Projeto desenvolvido como atividade do curso de Análise e Desenvolvimento de Sistemas (ADS), usando JavaScript para praticar lógica de programação no navegador. 🎓

##✨ O que dá para fazer?
- 🎲 **Sortear nomes:** informe participantes separados por vírgula ou por linha e descubra quem foi escolhido.
- 🏷️ Calcular descontos: informe o preço e a porcentagem para ver o valor final.
- 💾 Guardar o último sorteado: o resultado fica salvo no navegador para você consultar depois.
- ✅ Validar informações: mensagens ajudam quando falta preencher algo ou os valores não são válidos.

##🚀 Como usar
1. Baixe ou clone este repositório.
2. Abra o arquivo index.html no navegador.
3. Escolha uma ferramenta e pronto!

##📚 O que pratiquei
Neste projeto, exercitei conceitos como funções, condicionais, arrays, laços de repetição, manipulação do DOM, validação de dados e localStorage.
